# Decodificador de Texto

![Estado](https://img.shields.io/badge/status-finalizado-brightgreen)
![ONE Oracle Next Education](https://img.shields.io/badge/ONE-Oracle%20Next%20Education-red)

Aplicación web que encripta y desencripta texto usando reglas de sustitución simples. Desarrollada como parte del desafío **Oracle Next Education**.

## Reglas de Encriptación

| Vocal | Encriptado |
|-------|-----------|
| `e`   | `enter`   |
| `i`   | `imes`    |
| `a`   | `ai`      |
| `o`   | `ober`    |
| `u`   | `ufat`    |

## Funcionalidades

- Encriptar texto
- Desencriptar texto
- Copiar resultado al portapapeles
- Limpiar campo de texto
- Pegar texto desde el portapapeles
- Validación: solo minúsculas sin acentos

## Tecnologías

HTML5, CSS3, JavaScript, Google Fonts
